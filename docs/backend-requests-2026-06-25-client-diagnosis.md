# Клиент: необязательное поле «Диагноз»

[ПРИОРИТЕТ: НИЗКИЙ] · дата: 2026-06-25 · модель `Client` / `/api/v1/clients/`

## Требование

Добавить ребёнку (клиенту) **необязательное** поле «Диагноз» — свободный текст
(мед. диагноз ребёнка). Заполняется в карточке клиента, не обязательно.

## Что нужно на бэке

Добавить в модель `Client` и в сериализатор (create/update/read) поле:
```yaml
diagnosis:
  type: string
  required: false
  nullable: true
  blank: true          # пустая строка допустима
  # без ограничения длины (TextField) — диагноз может быть длинным
```
- отдаётся в `GET /clients/` и `GET /clients/{id}/` (камелкейс `diagnosis`);
- принимается в `POST /clients/` и `PATCH /clients/{id}/`;
- по умолчанию `null`/пусто.

Сейчас в ответе клиента поля нет (проверено: keys = id, fullName, phone, telegramId,
birthDate, photoUrl, isBlacklisted, isEmployeeChild, employeeParent, employeeParentName,
employeeChildDiscountPercent, organization, branch, responsiblePersons, …).

## Фронт

Реализован заранее под имя поля `diagnosis` (Add/Edit карточки клиента + вывод).
До появления поля на бэке значение просто не сохраняется (DRF игнорирует лишнее во
вводе). После добавления поля — заработает без правок фронта.

## Открытые вопросы

1. Имя поля — `diagnosis` (предложено фронтом). Если на бэке принято иное
   (`diagnosisText` / `medicalDiagnosis`) — скажите, поправлю маппинг.
2. Права/видимость: диагноз — мед.данные. Виден всем ролям, или ограничить
   (напр. только специалист/админ)? Пока фронт показывает всем, кто видит карточку.
