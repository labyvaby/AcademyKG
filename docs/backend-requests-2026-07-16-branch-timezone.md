# Таймзона филиала (branch.timezone) — 2026-07-16

## Контекст

У «АП Фергана» (Узбекистан) местное время UTC+5 (Asia/Tashkent), у бишкекских филиалов —
UTC+6 (Asia/Bishkek). До сих пор весь фронт показывал и создавал время в жёстко зашитом
Asia/Bishkek — для Ферганы всё уезжало на час.

Фронт переведён на «таймзону филиала» (по образцу `branch.currency`):
- показ времени приёмов — в таймзоне эффективного филиала;
- создание/редактирование приёма — введённое время трактуется как время филиала
  и отправляется ISO со смещением филиала (`2026-07-16T10:00:00+05:00`).

Пока поля на бэке нет, таймзона определяется на фронте эвристикой:
оверрайд по id филиала (Фергана → Asia/Tashkent) → валюта филиала (UZS → Asia/Tashkent,
KGS → Asia/Bishkek) → Asia/Bishkek.

## Что просим

По аналогии с `currency` добавить филиалу поле **`timezone`**:

| поле | тип | пример |
|---|---|---|
| `timezone` | string, IANA-имя | `"Asia/Tashkent"`, `"Asia/Bishkek"` |

1. Принимать в `POST /api/v1/branches/` и `PATCH /api/v1/branches/{id}/`.
2. Возвращать в `GET /api/v1/branches/` и везде, где сериализуется филиал
   (в т.ч. `users/me → employee.primaryBranch` / `branch` — фронт берёт таймзону
   не-суперадмина именно оттуда).
3. Дефолт для существующих филиалов — `Asia/Bishkek`.

Фронт уже читает `branch.timezone`, если оно есть — после появления поля эвристика
перестанет использоваться сама, код менять не нужно (оверрайд по id потом удалим).

## Важный вопрос: группировка по датам на бэке

Приёмы храните как instant (UTC) — это правильно. Но всё, что бэк **группирует по дню**
(отчёты `financial-monthly`, «Сводка дня» / daily-summary, `appointments-aggregated`
с фильтром по дате, available-months и т.п.) — в какой таймзоне режутся сутки?

Пример: приём в Фергане 16.07 в 23:30 (+05) = 17.07 00:30 по Бишкеку. Если сутки режутся
по Бишкеку, приём попадёт «на завтра» в отчётах ферганского филиала.

Просим: серверную группировку по дате вести в таймзоне филиала (или подтвердить,
что уже так). Для сравнения фронт день приёма определяет теперь в таймзоне филиала.
